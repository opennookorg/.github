# OpenNook

A growing collection of useful tools built to make life simpler.

## Tools

| Tool | What it does |
| --- | --- |
| [Screenshot Studio](https://screenshot-studio.com) | Turn plain screenshots into polished, shareable images. |
| [BetterWispr](https://betterwispr.com) | Speak naturally and get clean, ready to use text. |
| [Foliox](https://foliox.site) | Build a clean portfolio site in minutes. |
